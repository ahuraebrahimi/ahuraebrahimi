## 🧑‍💻 About Me

I'm **Ahura**, a passionate developer from Iran 🇮🇷  
I started my journey with **Scratch, App Inventor, and Pygame**, then moved into **web development and WordPress**.  
I love building **interactive projects, games, mobile apps, and websites** that are both functional and visually appealing.

- ⚡ **Python** scripts and basic backend development  
- ⚡ **Java** (beginner level, learning)  
- ⚡ **Android apps** with App Inventor / Kodular  
- ⚡ 2D games with **Scratch & Pygame**
